# Revel

Private project. Thesis: a project manager that treats every element as a task node.

**Agents:** read `revel.settings.json` first. It is the canonical brief.

- Core language: Python 3.11+
- Control plane: `revelctl`
- Surfaces: CLI, Textual TUI, web views
- Out of scope: Enlite/EFL desktop UI; any single-distro dependency
